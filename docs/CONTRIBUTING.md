# 贡献指南 · 华夏技能库

欢迎贡献新技能。一个技能就是一个文件夹，核心要求只有两条：**格式可交付、内容忠于原文**。

## 目录结构

```
skills/
└── <skill-name>/
    ├── SKILL.md            # 技能定义（必填）
    └── scripts/            # 可选：配套脚本 / 模板
```

## SKILL.md 必备内容

1. **frontmatter**（YAML）：

```yaml
---
name: <skill-name>
description: <一句话说明这个技能做什么、什么时候用>
---
```

2. **正文**至少包含：

- **这个技能做什么**：定位与边界。
- **输入要求**：接受什么格式、可选补充信息。
- **输出结构**：明确的模板或格式约定。
- **工作流程**：步骤化，让 AI 可执行。
- **质量规则**：忠于原文、信息保全、不确定标注等。

## 质量标准

- 输出结构明确到"改改就能发"，不依赖 AI 临场发挥。
- 只整理输入中真实出现的信息，绝不编造；不确定处标注"（待确认）"。
- 数字、金额、日期、人名、项目名等关键信息一个都不能丢。
- 每个新技能配一个演示示例（README 效果对比区或示例输出）。

## 提交方式

1. Fork 仓库，按上面结构新建 `skills/<skill-name>/`。
2. 提交 PR，说明：这个技能解决什么问题、输出长什么样、如何验证。
3. 审核通过后合入，技能表同步更新。
