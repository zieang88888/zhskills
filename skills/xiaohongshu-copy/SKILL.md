# 小红书文案 · xiaohongshu-copy

## 这个技能做什么

把原始素材（口播稿、产品资料、使用体验、灵感碎片）转成**可直接发布**的小红书笔记：20 字以内的标题（含 emoji 与好奇心钩子）、封面大字文案、分段正文、话题标签与发布小贴士。默认克制真实：体验来自素材本身，不虚构、不堆违禁词。

## 输入要求

- **必填**：素材文本（经历 / 体验 / 产品资料 / 口播转写，长短不限）。
- **可选**：目标人群、账号人设（如"职场妈妈""北漂租房党"）、期望风格（种草 / 干货 / 情绪 / 测评）、期望字数。

## 输出结构（模板见 `scripts/templates/xiaohongshu-copy.template.md`）

1. **标题**：1 个主标题 + 2 个备选，每行 ≤ 20 字，含适量 emoji，制造好奇心缺口（结果前置 / 数字 / 对比 / 悬念）。
2. **封面文案**：≤ 10 字的大字，一眼看懂利益点。
3. **正文**：钩子开头（3 秒抓人）→ 痛点 / 场景共鸣 → 分点干货（emoji 分段）→ 真诚小结 → 互动引导。
4. **话题标签**：8-10 个，垂直标签 + 泛流量标签结合。
5. **发布小贴士**：封面建议、发布时间、置顶评论引导。
6. **合规自查**：已规避的绝对化用语 / 功效断言清单。

## 工作流程

1. 通读素材，提取 **1 个核心利益点 + 2-3 个支撑点**。
2. 判断素材的语气与人设；未指定则默认"真诚种草型"。
3. 按模板生成；标题起 3 版，选最有钩子的一版。
4. 自查：标题 ≤ 20 字；无"最 / 第一 / 根治 / 绝对 / 秒杀"等违禁断言；无虚构数据；emoji 适量；分段可读。

## 质量规则

- **忠于素材**：体验、效果、数字必须来自素材本身，不编造、不虚构对比。
- **标题钩子化**：好奇心缺口优先（"谁懂啊""真的会被治愈""第 3 点没人告诉我"）。
- **合规优先**：医疗功效、绝对化用语、虚假宣传词一律不写；需要表达效果时用"个人感受""仅供参考"。
- **网感适度**：emoji 与网络用语服务于可读性，不堆砌、不油腻。
- **可直接发布**：输出即成品，不需要用户再排版。
