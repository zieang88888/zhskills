# 长文深度提炼 · extract-wisdom

> **二次开发**：本技能改编自 [danielmiessler/fabric](https://github.com/danielmiessler/fabric) 的 extract_wisdom pattern（MIT © 2012-2024 Scott Chacon and others），在保留其核心方法论基础上，升级为「提示词 + 可执行 CLI」双形态。署名见本目录 `NOTICE.md` 与仓库 `THIRD_PARTY_NOTICES.md`。

## 这个技能做什么

把一份长内容——播客转写稿、深度文章、书籍章节、行业报告、访谈实录——**按维度**（而不是按原文顺序）提炼成一份面向**学习吸收**的深度智慧摘要。

它和仓库里已有的 `doc-summary`（决策者一页摘要，面向快速拍板、压成一段结论）定位不同：本技能不替你下结论，而是把原文里**值得带走的东西分层摆出来**——哪些是作者的主张、哪些是可验证的事实、哪些是反直觉的洞察、哪些是值得原样记住的金句、哪些说法存疑需要回头核实、哪些能立刻变成行动。

典型场景：

- **读书笔记**：读完一本书/一章，沉淀可复用的观点、术语、行动；
- **播客 / 课程提炼**：几小时的音频转写稿，捞出真正有价值的部分；
- **行业报告速读**：上百页报告，先拿到多维精华再决定精读哪几节；
- **访谈实录精华**：专家访谈、用户访谈的逐字稿，提炼金句与洞察；
- **竞品分析材料沉淀**：把竞品公开演讲、发布会、长文整理成可复用的观点库。

## 输入要求

- **必填**：一段较长的文本（CLI 输入文件，或 stdin）。可以是转写稿、文章正文、报告节选、书籍章节。
- **建议提供**：原文标题 / 来源（用于报告头部）；如知道说话人/作者，一并给出，便于"重要引用"节署名。
- 长文本自动分块处理：单段超过约 9000 字时会切块，各段先独立提炼，再按维度合并，**合并时 7 个维度节结构保持一致**。
- 原文信息不足时：对应节写"原文未涉及"或"（待确认）"，**绝不脑补**。

## 输出结构（模板见 `scripts/templates/extract-wisdom.template.md`）

自上而下严格 7 节：

1. **核心观点**：3-10 条，每条一句话；每条句末必须标注【事实】（可被外部验证的客观陈述）或【观点】（作者主观判断/推测/主张）。
2. **关键洞察**：原文中反直觉、跳出字面、值得记住的点；每条注明在原文中的大致出处位置（段落 / 时间戳 / 小标题）。
3. **重要引用**：保留原文金句，**逐字摘自原文**，不得改写；注明说话人/出处（如有）。
4. **术语与概念**：原文出现的关键术语 + 一句话解释；首次出现时括注原文上下文。
5. **适用场景与启发**：分三类——**个人**（自我提升/习惯）、**团队**（协作/管理）、**业务**（产品/商业/组织），每类列可迁移的启发。
6. **可疑或待核实处**：原文的夸张、矛盾、存疑、缺乏数据支撑的断言；每条末尾标**（待核实）**；如原文无明显存疑处，明确写"原文未发现明显存疑处"。
7. **行动建议**：3-8 条可执行动作，具体到"谁在什么场景下做什么"。

## 工作流程

1. **通读 / 分块**：短文本一次读完；长文本按 ~9000 字切块（相邻块 400 字重叠，避免切断句子）。
2. **逐块提炼**：对每一块，按 7 个维度独立提取，不急于下整体判断。
3. **合并**：多块结果按顺序合并——每块均按 7 个维度节输出，节名与顺序保持一致；后续段追加在报告末尾，建议通读后跨段去重（重复观点、重复金句、重复洞察）。
4. **标记复核**：检查每条核心观点是否都带了【事实】/【观点】标记；每条引用是否逐字来自原文。
5. **写盘**：输出 Markdown 文件，并提示用户对照原文复核。

## 质量规则（必须遵守）

- **忠于原文**：只提炼原文中真实出现的内容，绝不编造、补写、脑补原文没有的观点或洞察。
- **引用逐字**："重要引用"节的每一句必须逐字摘自原文，**不 paraphrase 掉金句**；改写过的金句一律退回重写。
- **观点/事实标记不遗漏**：核心观点节每一条都必须带【事实】或【观点】标记，不允许出现未标记条目。
- **按维度组织，不流水账**：把同类信息归到对应维度节，不要顺着原文顺序复述。
- **存疑必列**：发现夸张、矛盾、以偏概全、无数据支撑的断言，必须进"可疑或待核实处"并标（待核实）；不为原文"背书"。
- **分块合并维度一致**：即使内容来自多段，也始终按这 7 个维度节统一组织，不出现某一段独有的章节。
- **中性克制**：只提炼与标注，不对作者做人身评价；启发与行动建议要具体可执行。

## 边界与异常处理

- 原文极短（不足几百字）→ 仍按 7 节输出，信息不足的节写"原文未涉及"，不凑数。
- 原文明显是广告 / 软文 → 在"可疑或待核实处"标出营销夸张表述。
- 原文中英混杂（技术报告、涉外访谈）→ 术语保留英文原词，解释用中文。
- 原文转写稿有错别字/口语重复 → 提炼时理顺，但"重要引用"节保留转写原貌。
- 单段超长被切块 → 进度打印到 stderr；后续分段追加在报告末尾（"## 补充内容（第 N 段）"），建议通读后跨段去重、合并同维度条目。

## 与脚本配合

- 批量 / 命令行场景：`scripts/draft_extract_wisdom.py`（纯标准库，一条命令跑通）；输入为长文本文件（或 `-` 读 stdin），输出为深度提炼报告 Markdown。
- 自定义模板：复制 `scripts/templates/extract-wisdom.template.md` 修改后使用。
- 默认温度 0.2，偏向稳定、忠于原文的提炼。
