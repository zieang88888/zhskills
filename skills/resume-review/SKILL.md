# 简历诊断 · resume-review

## 这个技能做什么

把简历文本转成一份**可直接交付**的诊断报告：总体评价（3-5 句）、亮点清单（引用原文）、问题清单（按 🔴 致命 / 🟡 重要 / 🟢 建议 分级）、逐条改写建议（Before → After）、岗位匹配度、行动清单（按优先级可执行）。

## 输入要求

- **必填**：简历文本（Markdown / 纯文本均可，长短不限）。
- **可选**：目标岗位（影响匹配度与关键词建议）；岗位描述 JD 文本（提供则做逐条匹配分析）。

## 输出结构（模板见 `scripts/templates/resume-review.template.md`）

1. **总体评价**：3-5 句，先亮后弱，含核心优势与主要差距。
2. **亮点清单**：逐条引用原文，不空谈。
3. **问题清单**：🔴 致命（影响筛选）/ 🟡 重要（影响竞争力）/ 🟢 建议（锦上添花），每条附原文引用与原因。
4. **逐条改写建议**：表格（原文片段 | 问题 | 改写后），改写必须给出具体句子。
5. **岗位匹配度**：提供目标岗位 / JD 时输出（匹配点 / 缺口 / 关键词命中）；否则明确说明未评估。
6. **行动清单**：按优先级排序的 5-8 条可执行动作。

## 工作流程

1. 通读简历，建立"经历时间线"与"能力画像"。
2. 提取 3-5 个真实亮点（必须有证据支撑）。
3. 逐段找问题：结构 / 量化 / 动词 / 成果 / 错别字 / 重点错位。
4. 分级排序，先解决 🔴 致命。
5. 每条问题给出 Before → After 具体改写。
6. 有 JD 则做关键词命中与缺口分析。

## 质量规则

- **忠于原文**：只分析简历中真实存在的内容，绝不虚构经历或能力。
- **证据引用**：每条问题与亮点必须附原文依据。
- **改写可落地**：每个建议给出改写后的具体句子，而不是"建议更量化"这类空话。
- **分级优先**：先解决影响筛选的致命问题，再谈优化。
- **尊重事实**：鼓励用真实经历重组表达，不教用户编造经历。
- **匹配谨慎**：未提供目标岗位 / JD 时，不臆测匹配度。
