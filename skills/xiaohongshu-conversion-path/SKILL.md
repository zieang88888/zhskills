# 成交路径设计 · xiaohongshu-conversion-path

> **二次开发**：本技能改编自 [xiaohongshu-ai-workbench](https://github.com/mengke-wang/xiaohongshu-ai-workbench) 的 xiaohongshu-conversion-path（MIT © 2026 王梦珂），在保留其核心方法论基础上，升级为「提示词 + 可执行 CLI」双形态。署名见本目录 `NOTICE.md` 与仓库 `THIRD_PARTY_NOTICES.md`。

## 这个技能做什么

把用户从"刷到你"到"愿意进一步了解"的整条路径讲清楚。本技能不承诺成交，而是设计一套**可执行的承接路径**：哪段内容负责吸引、哪段负责筛选、哪段负责建立信任、下一步动作是什么、私信怎么筛需求、犹豫用户怎么被复访承接。

适用场景已从单一小红书账号，泛化为：

- 中文职场私域转化（朋友圈 / 社群 / 个人 IP）
- 销售漏斗梳理（认知 → 兴趣 → 评估 → 决策）
- 落地页文案结构
- 销售邮件 / 私信序列设计
- 小红书账号成交路径（原场景）

## 输入要求

用户可能提供：

- 账号 / 品牌定位、目标用户、产品或服务是什么
- 客单价、交付方式、适合 / 不适合人群
- 当前主页 / 置顶内容 / 已有内容方向
- 用户常见顾虑：贵、不信任、怕麻烦、不知道值不值
- 转化目标：私信咨询、预约、体验工具、加微信、购买

**缺项处理**：客单价、交付方式、用户顾虑等关键输入缺一时，输出通用路径，并明确列出"建议补充的信息清单"，**不要编造产品能力、价格或成交数据**。

## 输出结构（模板见 scripts/templates/xiaohongshu-conversion-path.template.md）

1. **当前路径判断**：一句话说清用户现在卡在哪一段。
2. **用户决策阻力**：列 2–3 条（贵 / 不信任 / 怕麻烦 / 不值等）；基于输入或同类用户共性，推断处标注"（推断）"。
3. **内容分工（4 类，每类含目的 + 3 个选题建议）**：
   - A. 吸引内容：让目标用户觉得"这说的是我"
   - B. 信任内容：证明你理解问题、有方法、有边界
   - C. 筛选内容：让不适合的人自动离开，让适合的人留下
   - D. 转化内容：让用户知道下一步具体怎么做
4. **主页 / 落地页承接建议**：第一眼该让访客看到什么。
5. **置顶内容建议**：3 条（置顶笔记 / 首屏模块 / 固定邮件）。
6. **评论区 / 互动区动作**：作者主动做什么。
7. **私信筛选问题**：3 个——用问题筛需求，不一上来就成交。
8. **下一步最该改**：只给一个优先级最高的动作。
9. **建议补充的信息**：输入缺项清单（无缺项写"无"）。

## 工作流程

1. **还原 6 段路径现状**：吸引 → 筛选 → 信任 → 行动 → 私信 → 复访，逐段判断"现在有没有、做得够不够"。
2. **找断点**：哪一段缺了，用户就在哪一段流失；输出先指出断点。
3. **补 4 类内容分工**：每类明确目的，选题建议具体到"写什么话题"，不给空泛方向。
4. **设计承接动作**：主页 / 置顶 / 评论区 / 私信各自承担一段路径的职能，不重复、不断层。
5. **设计私信筛选问题**：问现状、问目标、问卡点，而不是"要不要买"。
6. **免费产品特殊处理**：推广免费工具 / 小程序时，"成交"= 体验、收藏、反馈、转发，不硬写购买。

## 质量规则（必须遵守）

- **不承诺结果**：不写"提升成交率 X%""必出单""月入 X 万"等承诺；只讲路径设计，不保证转化数字。
- **不编造事实**：产品能力、价格、客户案例、成交数据，输入里没有就不写；引用外部案例 / 第三方背书一律禁止。
- **不确定就标注**：客单价、用户画像等缺失时写"（待补充）"，并在末尾列出建议补充的信息。
- **筛选优先于成交**：路径设计的目标是让对的人留下、不对的人离开，不是硬转化所有人。
- **私信不硬推**：第一轮私信只筛需求（问 1–3 个问题），确认匹配后再给下一步。
- **可执行**：选题建议要能直接变成一篇内容 / 一封邮件 / 一条落地页模块，不写"加强信任"这类空话。

## 边界与异常处理

- 信息不足 → 输出通用路径模板 + 待补充清单，说明"基于现有信息为通用版本，补充后可定制"。
- 推广免费工具 / 小程序 → "成交"理解为体验、收藏、反馈、转发，输出中不出现"下单 / 购买 / 客单价"硬话术。
- 用户只想改简介 / 主页第一眼 → 本技能只输出承接路径中的主页一段，并提示这属于主页简介类技能的范围。
- 高客单 / 长决策周期产品 → 路径拉长"信任"与"复访"段，私信节奏放慢，不催单。
- 任何涉及具体疗效、投资回报、保收益的承诺 → 一律删除，改为中性表述。
