# PPT 大纲（ppt-outline）

## 这个技能做什么

把一段零散的材料（会议纪要、方案文档、要点列表、或一个主题 + 几条要点），整理成一份**可直接照做 PPT、照着讲**的分页大纲草稿：每页有标题、口语化讲稿要点（能照着念）、视觉/排版建议，覆盖封面 → 主体 → 收尾的完整结构，并标总页数与建议时长。

## 输入要求

- 材料文本（必填）：直接粘贴，或 .txt / .md 文件路径（配合脚本批量处理）；脚本也支持 `-` 从 stdin 读取。
- 可选补充：演讲场景 / 受众、页数上限、时长要求、是否要封面与目录页——有则更贴合，无则按默认（10 页以内、含封面与收尾）。

## 输出结构（模板见 scripts/templates/ppt-outline.template.md）

1. **文档头**：主题 / 总页数 / 建议时长 / 演讲场景（受众），缺失项标注（待确认）。
2. **逐页正文**：每页一个二级标题「第 N 页 · 标题」，下面分两小节：
   - **讲稿要点**：3–6 条口语化 bullet，能照着直接念，关键术语保留原文写法。
   - **视觉建议**：一句话，写明图 / 表 / 关键词 / 版式（如"左图右文，关键词放大"）。
3. **收尾页**：行动号召（CTA）或一句话总结。

## 工作流程

1. **通读材料**：识别主线论点——要讲给谁听、希望对方记住什么。
2. **规划页序**：按"开场（封面 / 目录）→ 论证（分点展开）→ 收尾（总结 / 行动号召）"组织，每页只承载一个核心信息。
3. **口语化改写**：把书面要点改成能照着念的讲稿，保留数字、人名、项目名、关键术语。
4. **对照原文复核**：数字、金额、日期、人名、项目名一个不丢；材料没有的信息不编造。

## 质量规则（必须遵守）

- **忠于原文**：材料没有的信息一律不编造，不确定处标注（待确认）。
- **每页一个核心信息**：禁止一页塞多个主题；宁可拆成两页，也不挤成一页。
- **信息保全**：数字、金额、日期、人名、项目名一个不丢。
- **口语化不等于随意**：关键术语保留原文写法，bullet 写成完整短句，不要只写关键词。
- **页数规模可控**：默认建议 10 页以内，可用 `--pages` 参数限制上限。
- **讲稿可照读**：每页 3–6 条 bullet，写成完整短句。

## 边界与异常处理

- 材料过短 → 如实整理，并说明"信息有限，建议补充更多材料"。
- 材料过长 → 按主题合并，去掉口水话与重复内容，但保留观点本身。
- 中英混杂 → 保留原文关键术语，不强行翻译。
- 信息不足（受众、时长未知）→ 标注（待确认），按默认场景先出草稿。

## 与脚本配合

- 批量 / 命令行场景：`scripts/draft_ppt_outline.py`（纯标准库，一条命令跑通）。
- 自定义模板：复制 `scripts/templates/ppt-outline.template.md` 修改后使用。
