# 小红书标题 · xiaohongshu-title

> **二次开发**：本技能改编自 [xiaohongshu-ai-workbench](https://github.com/mengke-wang/xiaohongshu-ai-workbench) 的 xiaohongshu-title（MIT © 2026 王梦珂），在保留其标题方法论基础上，升级为「提示词 + 可执行 CLI」双形态。署名见本目录 `NOTICE.md` 与仓库 `THIRD_PARTY_NOTICES.md`。

## 这个技能做什么

把用户的笔记素材 / 产品卖点 / 选题方向 / 已有标题，变成小红书风格的候选标题。三种模式：

- **快速模式（默认）**：12 种风格 × 2 = 24 个标题，直接可挑。
- **诊断模式**：先给 4 个标题方向（封面短句 / 评论区口吻 / 洞察判断 / 搜索转化），再给 20 个标题 + 首推 + 理由。
- **优化模式**：诊断已有标题的问题，给保留方向改写 3 条 + 换方向改写 5 条 + 首推 + 理由。

## 输入要求

- **必填**：素材（正文草稿 / 选题方向 / 产品卖点 / 封面或视频画面描述 / 关键词）。
- **可选**：账号定位、目标用户、内容风格要求。
- **优化模式**需额外提供已有标题（CLI：`--titles "标题A；标题B"`）。
- 信息不足时可以合理推断语气、情绪与场景，但**禁止编造事实**（价格 / 销量 / 效果 / 身份 / 背书）。

## 输出结构（模板见 `scripts/templates/xiaohongshu-title.template.md`）

1. **快速模式**：12 组（犀利吐槽 / 情绪定性 / 悬念代价 / 反常识 / 冷知识 / 强反转 / 人话口吻 / 趣味夸张 / 评论区 / 对话提问 / 数字焦虑 / 独体句）× 2，只输出标题不解释。
2. **诊断模式**：4 方向说明 → 各方向标题（8+5+4+3）→ 首推 + 一句理由。
3. **优化模式**：原标题诊断 → 保留方向改写 ×3 → 换方向改写 ×5 → 首推 + 理由。

## 工作流程

1. 抓具体事实：人、物、动作、场景、数字、价格、反常点。
2. 判断用户反应（想点 / 想学 / 想收藏 / 想搜索 / 想转发）与内容目标（封面停留 / 评论互动 / 搜索流量 / 转化）。
3. 生成多方向候选：**造场景不概括观点**、**从用户处境切入**、**留一点未完成**。
4. 混合标题杠杆：数字 / 我 / 你 / 具体动作 / 轻微误读 / 轻微冲突 / 用户关系 / 搜索问题 / 标点节奏 / 半句话。
5. 按质量自检重写弱标题。

## 质量规则

- **忠于输入**：只基于用户输入与通用创作原则，不引用外部案例、不编造数据 / 效果 / 背书。
- **不确定表达**：无可验证结果时用"像 / 可能 / 适合 / 看起来"，不写成确定承诺。
- **禁用词零容忍**：不得出现"天花板、YYDS、绝绝子、谁懂啊、狠狠拿捏、闭眼入、氛围感拉满、高级感"等模板词；不用"不是……而是……、表面是 X 背后是 Y、这才是 X 该有的样子"等句式。
- **标题规格**：6-18 字（搜索转化类 ≤ 22 字）；快速模式至少 4 组带标点或问句、3 组带"我 / 你"、3 组带数字；感叹号最多连续 2 个。
- **可直接交付**：输出即成品，不需要二次排版。
